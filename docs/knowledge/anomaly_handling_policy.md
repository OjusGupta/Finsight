# Anomaly Handling Policy
## Detection
Anomalies are detected by the system for:
- Duplicate transactions (same timestamp, amount, and customer).
- Unusually high return rates.
- Missing postings.

## Action
1. All anomalies must be assigned an 'open' action item.
2. The relevant manager must investigate.
3. Once the root cause is addressed, the anomaly status must be marked as 'resolved'.
